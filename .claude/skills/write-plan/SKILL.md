description: Write plans to /plans folder in project root. Use when the user asks to write a plan, create a plan, or save a plan as a markdown file.
---

When the user asks to write a plan, create a plan file, or save a plan as a markdown file, always write it to the `/plans/` directory at the root of this project (`./plans/` in the repo root). Create the directory if it doesn't exist.

Use a clear, descriptive filename (kebab-case) that reflects the plan's purpose.
